# Project

Inspired by a computer vision algorithm shared to one of the team members from another class, this project applies a computer vision model to the Metropolitan Museum of Art's Photography data to detect and segment the various objects that are found within each photograph. 

We followed trends in artists' tendencies to photograph people, buildings, greenery, and more categories as a method to understand how art evolves with the evolving planet and human progression. 

The presentation of the website follows a very simple scrolling-based format. Instructions for interacting with visualizations are provided with supplementary text on each visualization. Note that the decades and co-occurrence visualizations have the functionality of expanding into a gallery for the viewer to see more photographs.
